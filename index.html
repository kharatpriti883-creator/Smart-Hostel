About Campus Heaven

A student software project focused on digital hostel services.

The aim of Campus Heaven is to make hostel-related information easier to organize and access. The project explores how web technologies can support communication between students and hostel administration.

This page is a static project showcase created for demonstration and deployment through GitHub Pages. Backend-connected features require the separate application server to be running.

HTML CSS JavaScript Python / Flask — project backend

Campus Heaven — Smart Hostel Management System

The project explores a digital interface for hostel services, with a focus on usability, organized information and a simple student-friendly design.

  • Responsive webpage layout for desktop and mobile screens.
  • Feature showcase for common hostel management needs.
  • Lavender-themed interface with clear navigation.
